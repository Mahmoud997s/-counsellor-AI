## 1. What Looked Like "Magic" Bugs?
During our refinement, some tests strangely started failing:
*   **T09** (`إجراءات - باطل`): Failed and returned "لا حكم" (No Verdict).

These confusing bugs were caused by an age-old NLP enemy: **substring matches**.

## 2. Hardening Logic with Boundaries & Refined Contexts

> [!TIP]
> Relying purely on string inclusion (like `"باطل" in text`) is extremely risky in Arabic NLP since many everyday words contain legal keywords!

We implemented surgical fixes:

*   **The "خلال" Trap (Case X Event 7)**:
    Our engine was searching for `اخلال` (Breach of contract). The text contained `خلال المواجهة`. The engine matched `خلال` inside `اخلال` and threw a procedural nullity! We fixed this by utilizing strict word boundaries `\bاخلال\b` and `\bإخلال\b`.
*   **The "بإطلاق" Trap (Case X Event 7)**:
    The word `بإطلاق` (firing) normalizes to `باطلاق`. Our regex searched for `باطل` (Void/Nullity). `باطلاق` contains `باطل` directly! This caused *another* false procedural nullity in the same self-defense action. We fixed this with `\bباطل\b`.
*   **The "دخل" Exception (T09 Fix)**:
    To prevent burglars who "enter without permission" from triggering police search nullity, we excluded `دخل`. However, T09 literally said "دخل ضباط الشرطة". The exception blocked the valid police search. We removed the broad `دخل` exclusion and instead strictly require police/prosecution context (`نيابة`, `تفتيش`, `شرطة`, `تحقيق`) for search nullity.
*   **Murder Fact Missing (Case X Event 7)**:
    The victim's death in Case X was phrased as "أدى إلى وفاة". The word "وفاة" wasn't in the murder keyword list, causing the crime component of the self-defense to vanish. We appended `وفاة` to the `murder` triggers.
*   **Verb Splitting Carnage**:
    We completely disabled `VERB_CHANGE_MARKERS` inside the Event Splitter. They were causing massive sentence fragmentation (e.g. splitting `تفتيش` based on `فتش`), breaking context linking globally. Using purely `TEMPORAL_MARKERS` effectively segmented Case X into 8 distinct valid events.
