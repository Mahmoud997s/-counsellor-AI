### 5. استخدام المحرك
```python
from case_analyzer import analyze_case

# تحليل بسيط
result = analyze_case("قام المتهم بقتل الضحية عمداً بعد أن أطلق عليها النار")
print(result["verdict"])  # الإعدام

# تحليل مع سجل الاستدلال
result = analyze_case("هجم عليه بسكين فدافع عن نفسه وقتله", debug=True)
# يطبع سلسلة الحكم كاملة:
# 🔍 الحقائق: murder, self_defense, imminent_danger
# ⚡ تجاوز: البراءة للدفاع الشرعي (م.245)
# ✅ الحكم: البراءة - فعل مباح بالدفاع الشرعي
```

## ✨ المميزات

- **Negation Logic**: يفهم "دون قصد" ≠ "قصد"
- **Global Override**: الدفاع الشرعي يُسقط أي تهمة جنائية
- **Fact Confidence**: كل حقيقة تحمل مستوى ثقة (0.8 → 0.95)
- **Inference Logger**: سجل استدلال كامل بصيغتين (JSON + مقروء)
- **Data-Driven**: جميع القواعد في DB — لا كود مشفّر
